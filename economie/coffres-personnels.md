# Coffres personnels (Vaults)

Les coffres personnels (vaults) te permettent de stocker des objets en dehors de ton inventaire, accessibles depuis n'importe où.

## Commande

```
/pv
```

## Caractéristiques

* **Nombre de coffres maximum** : 12
* **Taille par défaut** : 6 lignes (54 emplacements) par coffre
* **Déblocage** : chaque coffre supplémentaire nécessite une permission dédiée (souvent liée à un rang ou une récompense)
* **Sauvegarde** : automatique toutes les 5 minutes

{% hint style="info" %}
Le nombre de coffres accessibles peut varier selon ton rang ou tes récompenses obtenues — vérifie `/pv` en jeu pour voir combien tu as débloqué.
{% endhint %}
