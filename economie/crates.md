# Caisses (Crates)

Les caisses te permettent d'obtenir des récompenses aléatoires en échange de clés. Elles se trouvent à `/warp caisse`.

## Les caisses disponibles

| Caisse | Récompenses principales |
|---|---|
| **Caisse Fermier** | Orbes (250k / 500k / 750k / 1M / 1,5M), Clé de Caisse Plage, Booster Orbes |
| **Caisse Mineur** | Gemmes (250k / 500k / 750k / 1M / 1,5M), Clé de Caisse Plage, Booster Gemmes |
| **Caisse Lac** | Perles (250k / 500k / 750k / 1M / 1,5M), Clé de Caisse Plage, Booster Perles |
| **Caisse Solaire** | Clé de Caisse Pique-Nique, Boosters (Gemmes/Levels/Money/Orbes/Perles), Bâton de Vente (x0.75 / 100 usages) |
| **Caisse Terre** | Clé de Caisse Pique-Nique, Boosters (Gemmes/Orbes/Money/Levels/Perles), Bâton de Vente (x0.5 / 50 usages) |
| **Caisse Uranus** | Clé de Caisse Plage, Boosters (Money/Orbes/Gemmes/Perles/Levels), Chunk Point Tier 1 |
| **Caisse Discord** | Set cosmétique complet "Scaphandre Discord Nitro" (casque, plastron, jambières, bottes, aile), couleur de chat Discord Nitro |

{% hint style="info" %}
Chaque caisse thématique (Fermier, Mineur, Lac, Solaire, Terre, Uranus) s'ouvre avec sa clé correspondante, obtenue principalement en jouant sur le serveur. Chaque récompense a un poids de tirage différent — certaines sont donc bien plus rares que d'autres.
{% endhint %}

## Caisses événementielles

En plus des caisses permanentes, LostEra propose ponctuellement des caisses événementielles, comme la **Caisse StarWars** ou la **Caisse Plage** (été), disponibles lors d'événements spéciaux.

## Clés de caisses obtenues via LootBoxes / Grades

Les clés de **Caisse Plage**, **Caisse Pique-Nique** et **Caisse Requin** peuvent aussi être obtenues via les [LootBoxes de la boutique](lootboxes-et-boutique.md) ou offertes automatiquement à l'achat d'un [grade](../rangs/rangs-et-permissions.md).

{% hint style="warning" %}
Certaines caisses présentes dans les fichiers du serveur (ex. plugin AdvancedCrates) correspondent à des exemples par défaut non personnalisés et ne sont probablement pas actives — elles ne sont donc pas listées ici. À confirmer avant publication si de nouvelles caisses sont mises en ligne.
{% endhint %}
