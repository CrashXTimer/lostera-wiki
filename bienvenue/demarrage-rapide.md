# Démarrage rapide

## Se connecter au spawn

À votre connexion, vous apparaissez au spawn du serveur. C'est le point central à partir duquel vous pouvez rejoindre les différentes zones du serveur, soit via des **portails** directement présents au spawn, soit via les warps ci-dessous.

## Les warps utiles

| Warp           | Description      |
| -------------- | ---------------- |
| `/warp caisse` | Zone des caisses |
| `/warp champ`  | Zone de farming  |
| `/warp mine`   | Zone de minage   |
| `/warp lac`    | Zone de pêche    |

## Créer votre île

Pour commencer votre progression, vous devez créer votre île :

```
/is create <nom>
```

Vous pouvez aussi rejoindre l'île d'un ami plutôt que d'en créer une.

{% hint style="info" %}
Le nombre de membres sur votre île influence la catégorie de classement dans laquelle elle est comparée aux autres — voir la section [Skyblock & Îles](../skyblock-and-iles/les-iles.md) pour le détail.
{% endhint %}

## Les trois axes de progression

Une fois votre île créée, trois activités principales s'offrent à vous :

* ⛏️ **Le minage** `/warp mine` pour gagner des **Gemmes**
* 🌾 **Le farming** `/warp champ` pour gagner des **Orbes**
* 🎣 **La pêche** `/warp peche` pour gagner des **Perles**

Chacune de ces activités possède sa propre monnaie et ses propres récompenses — voir la section [Monnaies & Shop](../economie-and-shop/monnaies-et-shop.md) pour le détail.

## La boucle de progression

Le principe de base sur LostEra est simple :

1. **Farmez** avec votre outil (houe, pioche ou canne à pêche) afin de gagner la **monnaie qui lui est liée** — les ressources récoltées se **stockent automatiquement** dans votre **sac à dos** (/sac).
2. Utilisez la **monnaie liée à votre outil** pour **améliorer vos enchantements** et le rendre **plus puissant.**
3. **Vendez** les ressources de votre sac, soit directement depuis `/sac`, soit avec `/sell` pour obtenir de la **Money**.
4. Utilisez votre **Money** pour acheter des **générateurs** qui produisent des ressources qui se vendent à leur tour pour générer plus de **Money**, et accélérez encore votre progression.
5. En farmant, votre outil **gagne des niveaux** ; à un certain niveau vous pouvez lui faire passer un **prestige** via `/prestige`. Il **perdra alors tous ces niveaux** mais débloquera de **nouveaux enchantements** et des **boosts puissants.**

Et le cycle recommence, de plus en plus efficacement à mesure que vous progressez !

{% hint style="info" %}
Retrouvez tous les détails du sac à dos dans [Sac à dos (Backpack)](../gameplay-additionnel/sac-a-dos.md), et ceux du Multi-Outil dans [Le Multi-Outil](../progression-and-gens/omnitool.md).
{% endhint %}
