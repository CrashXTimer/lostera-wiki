# Vote & récompenses

Voter pour LostEra est l'un des meilleurs moyens de **soutenir le serveur** tout en récupérant des **récompenses gratuites**, chaque jour.

## Voter

Rends-toi sur `https://lostera.fr/vote` pour accéder à la liste des sites de vote. **Chaque vote** te rapporte directement des **récompenses** (clés de caisse, LostCoins), consultables depuis le menu `/vote` en jeu.

## Paliers de vote hebdomadaires

Le serveur suit le nombre de votes cumulés par **tous les joueurs** chaque semaine (reset chaque lundi à 5h). Plus la communauté vote, plus les paliers suivants se débloquent :

| Palier | Votes cumulés (hebdo) | Récompense                                                       |
| ------ | --------------------- | ---------------------------------------------------------------- |
| 1      | 10                    | x3 Clés de Caisse Plage                                          |
| 2      | 20                    | x5 Tirages d'Atout                                               |
| 3      | 30                    | x3 Œufs de Dragon Épique                                         |
| 4      | 40                    | x2 Clés de Caisse Uranus                                         |
| 5      | 50                    | x1 Colis de Totem Épique                                         |
| 6      | 60                    | x1 Clé de Caisse Solaire                                         |
| 7      | 70                    | 50 LostCoins                                                     |
| 8      | 80                    | x1 Œuf de Dragon Légendaire                                      |
| 9      | 90                    | x1 Bâton de Vente (multiplicateur de vente x2, 100 utilisations) |
| 10     | 100                   | x20 Slots de Gens                                                |

{% hint style="info" %}
Chaque palier ne peut être réclamé qu'une seule fois par semaine, une fois le seuil de votes atteint.
{% endhint %}

## Vote Party

Quand le serveur atteint **150 votes cumulés**, une **Vote Party** se déclenche automatiquement : des **canards** (la mascotte de LostEra) apparaissent dans tout le `/warp champ` ! Récupère-en le plus possible avec **clic droit** pour grimper dans le **classement de l'événement**.

| Classement    | Récompense              |
| ------------- | ----------------------- |
| 🥇 1er        | x5 Clés de Caisse Event |
| 🥈 2e         | x3 Clés de Caisse Event |
| 🥉 3e         | x1 Clé de Caisse Event  |
| Participation | x3 Clés de Caisse Rare  |

## Top voteurs du mois

Chaque mois, les **3 joueurs** ayant le plus voté reçoivent une **récompense spéciale** :

| Position | Récompense                      |
| -------- | ------------------------------- |
| 🥇 1er   | 2 500 LostCoins + titre "Votes" |
| 🥈 2e    | 2 000 LostCoins                 |
| 🥉 3e    | 1 500 LostCoins                 |
