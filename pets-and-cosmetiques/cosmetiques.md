# Cosmétiques

LostEra propose un large système de cosmétiques purement esthétiques, accessibles via `/cosmetic`.

## Système de raretés

Les cosmétiques sont classés par rareté, chacune ayant sa propre couleur :

| Rareté   |
| -------- |
| Commun   |
| Rare     |
| Épique   |
| Exotique |
| Exclusif |

{% hint style="warning" %}
Les cosmétiques **exclusifs** sont uniques : un seul joueur sur tout le serveur peut posséder chaque cosmétique exclusif à la fois. Ils sont donc extrêmement rares !
{% endhint %}

## Catégories de cosmétiques

* **Armures cosmétiques** — casques, plastrons, jambières, bottes
* **Ballons** — à faire flotter au-dessus de votre tête
* **Couleurs de chat** — personnalise la couleur de vos messages
* **GG Wave** — effet de texte spécial quand vous écrivez "GG" dans le chat suite à l'achat de LostCoins d'un autre joueur en boutique ; l'utiliser vous rapporte x1 LostCoins
* **Messages de connexion / déconnexion** — personnalise votre arrivée et votre départ du serveur
* **Couleur de Renommage** — effets visuels sur votre nom
* **Symboles** — icônes affichées à côté de votre pseudo
* **Couleur Tab** — personnalise l'affichage de votre nom dans le tab
* **Titres & Couleur de Titre** — titres liés aux classements et aux succès
* **Skins d'outils** — apparences pour votre houe, votre pioche et votre canne à pêche
* **Équipement** — objets cosmétiques en main gauche
* **Effets de texte** — modifie la façon dont vous écrivez dans le chat (ex. Gras, Italique, Souligné)



## Ouverture de caisse cosmétique

Lors de l'ouverture d'une **Caisse Cosmétique**, un **message global** est envoyé à tous les joueurs du serveur, qui peuvent alors **rejoindre votre session** afin d'assister à votre tirage.

Lorsqu'un joueur **enchaîne plusieurs ouvertures** de caisses cosmétiques, le prix d'ouverture de la caisse **diminue, jusqu'à un maximum de 5 fois**.
