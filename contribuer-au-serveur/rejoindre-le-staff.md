# Rejoindre le staff

L'équipe de LostEra ouvre régulièrement des recrutements pour renforcer le staff du serveur.

{% hint style="info" %}
Les recrutements se déroulent exclusivement sur le **Discord** officiel de LostEra : [discord.com/invite/lostera](https://discord.com/invite/lostera).
{% endhint %}

Surveillez les annonces du Discord pour ne pas manquer l'ouverture d'un recrutement, et suivez les instructions qui y sont données pour postuler.
