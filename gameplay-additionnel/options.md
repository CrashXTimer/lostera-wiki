# /option

Le menu `/option` (alias `/settings` ou `/parametres`) te permet de personnaliser ton confort de jeu.

## Réglages disponibles

| Option | Effet |
|---|---|
| Affichage Scoreboard | Afficher ou non le Scoreboard |
| Affichage Bossbar | Afficher ou non les Bossbar |
| Affichage joueurs | Afficher ou non les autres joueurs |
| Affichage messages niveaux | Afficher ou non les messages de passage de niveau |
| Affichage récapitulatif farm | Afficher ou non le récapitulatif de farm |
| Affichage messages enchantements | Afficher ou non les messages des enchantements |
| Affichage visuels des enchantements | Afficher ou non les effets visuels des enchantements |
| Effets sonores des enchantements | Activer ou non les sons des enchantements |
| Auto-Prestige | Passage automatique des prestiges |
| Auto-Vente | Vente automatique du sac à dos et de l'inventaire |
| Auto-Condense | Condensation automatique du sac à dos et de l'inventaire |

{% hint style="warning" %}
L'option **Auto-Prestige** nécessite le grade **Hero** minimum.
{% endhint %}
