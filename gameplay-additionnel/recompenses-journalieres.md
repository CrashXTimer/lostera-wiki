# Récompenses journalières

LostEra te récompense simplement pour le temps que tu passes à jouer chaque jour.

## Fonctionnement

* Chaque minute jouée est comptabilisée dans ton temps de jeu du jour.
* Le compteur se réinitialise chaque jour à **minuit**.
* Une fois le seuil de temps de jeu atteint, une récompense se débloque automatiquement.
* Récupère-la avec la commande `/dr claim`.

{% hint style="info" %}
Le message "Nouvelle récompense débloquée !" apparaît dès que tu peux réclamer ta récompense journalière.
{% endhint %}
