# Récompenses journalières

LostEra vous récompense simplement pour le temps que vous passez à jouer chaque jour.

## Fonctionnement

* Chaque minute jouée est comptabilisée dans votre temps de jeu du jour.
* Le compteur se réinitialise chaque jour à **minuit**.
* Une fois le seuil de temps de jeu atteint, une récompense se débloque automatiquement.
* Récupérez-la avec la commande `/dr claim`.

{% hint style="info" %}
Le message "Nouvelle récompense débloquée !" apparaît dès que vous pouvez réclamer votre récompense journalière.
{% endhint %}
