# ChunkPoints

Les chunkPoints te permettent de charger les chunks ou ils sont posés, ce qui permet notamment de garder tes générateurs actifs même en ton absence.

## Les tiers de ChunkPoints

| Tier | Temps de fonctionnement |
| ---- | ----------------------- |
| 1    | 1h                      |
| 2    | 3h                      |
| 3    | 6h                      |
| 4    | 12h                     |
| 5    | 2 semaines              |

{% hint style="danger" %}
Une fois un ChunkPoint posé, il est impossible de le déplacer, ce dernier ce supprimeras de lui-même lorsqu'il auras atteint sa limite de temps.
{% endhint %}
