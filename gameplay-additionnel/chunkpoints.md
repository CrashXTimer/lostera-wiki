# ChunkPoints

Les ChunkPoints vous permettent de charger les chunks où ils sont posés, ce qui permet notamment de garder vos générateurs actifs même en votre absence.

## Les tiers de ChunkPoints

| Tier | Temps de fonctionnement |
| ---- | ----------------------- |
| 1    | 1h                      |
| 2    | 3h                      |
| 3    | 6h                      |
| 4    | 12h                     |
| 5    | 2 semaines              |

{% hint style="danger" %}
Une fois un ChunkPoint posé, il est impossible de le déplacer. Il se supprimera de lui-même lorsqu'il aura atteint sa limite de temps.
{% endhint %}
