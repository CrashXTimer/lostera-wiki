# Monnaies & Shop

LostEra utilise plusieurs monnaies, chacune ayant un usage spécifique dans votre progression.

## Les monnaies principales

| Monnaie       | Usage                                                                                                    |
| ------------- | ---------------------------------------------------------------------------------------------------------- |
| **Money**     | Monnaie générale, obtenue en vendant vos ressources — sert principalement à l'achat de **générateurs** |
| **Orbes**     | Monnaie liée au **farming**                                                                              |
| **Gemmes**    | Monnaie liée au **minage**                                                                               |
| **Perles**    | Monnaie liée à la **pêche**                                                                               |
| **LostCoins** | Monnaie **premium** du serveur                                                                           |

{% hint style="info" %}
Money, Orbes, Gemmes, Perles et LostCoins sont toutes utilisables à l'[hôtel des ventes](hotel-des-ventes.md).
{% endhint %}

## Les LostCoins

Les **LostCoins** sont la monnaie premium de LostEra, achetable avec de l'argent réel sur `https://boutique.lostera.fr/`. Mais pas de panique si vous ne voulez pas payer : vous pouvez aussi en **gagner en jouant**, via de nombreuses sources en jeu (succès, Passe de Combat, paliers de vote, événements...).

{% hint style="info" %}
Les **LostCoins** sont **échangeables entre joueurs**, à vous de commercer pour vous enrichir !
{% endhint %}

## Autres monnaies spécifiques

En plus des monnaies principales, LostEra possède des **clés de caisses** (virtuelles), obtenues notamment via les LootBoxes, le Pass ou l'achat de grades — voir la section [Caisses (Crates)](crates.md).

## Vendre vos ressources

### Le Bâton de Vente

Le **Bâton de Vente** (Sell Wand) permet de vendre instantanément le contenu d'un conteneur (coffre, baril ou [LostCollecteur](../gameplay-additionnel/lostcollecteurs.md)) avec un multiplicateur de vente défini. C'est le moyen le plus rapide de convertir vos ressources stockées en monnaie.

### Le Shop

Le shop `/shop` vous permet d'acheter des objets et blocs pour construire votre île.

{% hint style="success" %}
Actuellement, tous les objets et blocs du shop classique sont **gratuits**.
{% endhint %}

## Classements liés à l'économie

Le serveur suit plusieurs classements liés à vos gains : Money, Orbes, Gemmes, Perles, ainsi que des classements de progression (farming, minage, prestige d'outils) — consultables via les top affichés en jeu.
